# Worksheet footer line spacing

The public `tests/fixtures/xlsx/two_line_sheet_footer.xlsx` has two explicit Aptos 8pt footer lines on page 1. Native Excel baselines are 757/768pt; the pre-fix converter uses 727.1042/768pt. The text-only candidate uses 757/768pt and preserves the last-line seat. Page 2 is pixel-identical before/after.

`probes/` contains a synthetic workbook, one-factor XML specifications, native control reports and extracted baselines. Run each specification with `scripts/probe_harness.py --backend office`. All native re-zip controls passed. Arial 8/11/12/14/24pt advances are 11/14/15/17/29pt; Aptos, Calibri and Times New Roman 11pt use 14pt, and Malgun Gothic 11pt uses 17pt. Mixed Arial first/last sizes 8/11, 24/11, 11/8 and 11/24 use 14/17/11/26pt advances. These are footer-native exports, independent of the wrapped-cell metric implementation. A further long-first/long-last probe wraps the longer paragraph to two lines; both native variants use baselines 740/754/768pt. The regression covers a long first or last paragraph and requires all three native baselines.

The reports cover both pages at 150 DPI with a 0.5pt fine gate. The JPEG triplet shows the affected first page; both pages have exact-ID render reports. Full pages, pixel differences, every emitted shift crop, and twelve full-scale page-2 region pairs were inspected. Page count, text presence, emphasis and colors are preserved. Normalized extraction has identical character multisets but different ordering on page 2; the values and labels remain present in the inspected rows.

Remaining findings: #1721 tight-row title/card/table seats; #1719 fitted text origin and #1720 inherited padding; #1773 right-aligned numeric/YEAR origins and #1774 month origins; #1730 ISO page/footer position; #1757 linked month label; #1759 expense bar geometry and #1778 other chart bar anchors; #1785/#1786 cash-flow category placement; #1784 thinner sparklines; #1659 intra-run glyph advances; #1804 extra scatter marker; #1805 false wrap between independent percentage axes. `glyph-advances-page1.json` confirms native whole-point glyph origins versus fractional output origins. Every material cluster maps to an explicit open issue (26 on page 1, 208 on page 2).

Model vision findings: the first footer line moves down to its native position while the second stays fixed. The title is white bold Arial on teal; Note remains bold. Page 2 retains its bold serif title/table headings, brown bold category labels, gray table rules/double separators, brown category separators and colored total rules. Chart category labels, numeric rows and several headings retain positional differences. The cash-flow chart has an extra cyan circle and all ten sparklines remain thinner. No new clipping, rotation, element omission or emphasis change was found. No italic or underlined runs occur in the inspected pages.

README usage, setup and API are unchanged. Image-bearing footers retain the existing flow layout; a compiled regression checks that text stays clear of the picture. Native parity is established for the sampled explicit and wrapped text lines, not arbitrary image-bearing footer content.
